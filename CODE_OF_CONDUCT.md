# Code of conduct

This project is built by and for people who build on Alkanes and SUBFROST.
Keep it a place where anyone can ask a question or send a fix.

- **Be respectful.** Disagree with ideas, not people. Assume good faith.
- **No harassment.** No insults, threats, slurs, sexual content, or personal
  attacks, and no publishing anyone's private information.
- **Stay on topic.** Issues and pull requests are for this project.

Maintainers may edit or remove comments, issues, pull requests and other
content that breaks these rules, and may block accounts that keep doing so.

To raise a concern privately, email **security@arieslabs.org**.
