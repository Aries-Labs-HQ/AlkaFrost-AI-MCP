# CLAUDE.md — alkanes-subfrost-public-mcp (AlkaFrost MCP; repo-local, the global CLAUDE.md governs)

**PUBLIC repo.** Everything here ships to strangers — code, docs, commit messages, issue text.

This is AlkaFrost MCP: a standalone, bring-your-own-SUBFROST-key stdio MCP server plus a corpus built from public, official sources. It is fully self-contained and must stay that way.

**Hard lines:**
- Corpus = public sources only. `corpus/subfrost/` and `corpus/alkanes-rs/` are generated by `npm run ingest`; `corpus/reference/` is hand-written and every file cites a public `source_url`. No private notes, unpublished material, or licensed/third-party-owned content, ever.
- No attribution or key data, no internal hostnames/IPs/paths, no ops details, no deployment details — in code, corpus files, docs, or commit messages.
- stderr-only logging (stdio transport — stdout is the protocol).
- BYO is the only mode: a fresh clone + the user's own SUBFROST key must work with zero hosted dependencies. Anything that quietly requires a hosted service is a bug.
- Read-only: no tool may sign, broadcast, or handle keys.

Conventional commits, lowercase `type(scope):`. Branch → PR; Bragi merges.
